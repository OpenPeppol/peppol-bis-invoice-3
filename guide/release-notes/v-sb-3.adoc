== Changes to PEPPOL-COMMON rules

* Changed rule PEPPOL-COMMON-R040 to ONLY allow GLN13 values with schemeID 0088. Rule PEPPOL-COMMON-R040 stays fatal. The text says MUST.
* Fixed four Self-Billing example files containing invalid GLNs so they comply with PEPPOL-COMMON-R040. Remaining scheme 0088 values in those examples are a 13-digit GLN.
* Updated validation method on rule PEPPOL-COMMON-R043 (fatal) to validate Belgian identifiers.
* Changed the wording of warning rules PEPPOL-COMMON-R044, PEPPOL-COMMON-R045, PEPPOL-COMMON-R046, and PEPPOL-COMMON-R047 from “must” to “SHOULD” to align the rule text with the severity. Updated other lowercase should to uppercase SHOULD. https://openpeppol.atlassian.net/browse/RFC-558[RFC-558]
* Changed rules PEPPOL-COMMON-R054, PEPPOL-COMMON-R055, PEPPOL-COMMON-R056-1, PEPPOL-COMMON-R056-2, and PEPPOL-COMMON-R057 from warning to fatal after the announced transition period. https://openpeppol.atlassian.net/browse/RFC-541[RFC-541]
* Added rule PEPPOL-COMMON-R058 (introduced as warning, will change to fatal in coming release) for validation of Luxembourg VAT numbers. The VAT number must follow the format LU followed by 8 digits, where the last 2 digits are the check digits computed as the first 6 digits modulo 89. Applies to Seller VAT identifier (BT-31), Buyer VAT identifier (BT-48), and Tax representative VAT identifier (BT-63).
* Added rule PEPPOL-COMMON-R059 (introduced as warning, will change to fatal in coming release) for validation of Luxembourg Register of Legal Persons numbers (Matricule, schemeID 0240). The number must be exactly 11 digits; digits 5–6 must be a legal form type code in the range 20–99; and digit 11 must be a valid mod-11 check digit (with an alternative check digit supported for legal form type 24). Applies to the seller electronic address (BT-34), seller identifier (BT-29), seller legal registration identifier (BT-30), buyer electronic address (BT-49), buyer identifier (BT-46), and buyer legal registration identifier (BT-47). UBL only.
* Added rule PEPPOL-COMMON-R062 (warning) for validation of Belgian VAT numbers. The number is BE, then 0 or 1, then nine digits, and the digits pass the modulo 97 check. A lower-case prefix is checked as well. UBL only. The rule stays a warning and becomes fatal in the May 2027 release.


== Other changes
* Added fatal inferred mandatory-cardinality rules PEPPOL-EN16931-R140 through PEPPOL-EN16931-R276, except the rules that only repeat a 1..1 constraint of the UBL 2.1 schema: R140, R147, R157, R163, R171, R180, R198, R201, R209, R216, R226, R232, R236, R243, R251, R266 and R269. UBL only.
* Code 527, self billed debit note, uses the UNTDID description: a document which indicates that the customer is claiming debit in a self billing environment.
