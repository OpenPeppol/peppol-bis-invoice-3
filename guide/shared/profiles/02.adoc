= Profile 02 - Billing with Response

This profile describes the billing process where a structured electronic invoice response is returned from the buyer to the seller. The Billing-part is the same as the basic Peppol BIS Billing 3.0 except that the value of the ProfileID indicates that invoice response is part of the collaboration.

Details about the invoice response message itself can be found in the Invoice Response BIS.
